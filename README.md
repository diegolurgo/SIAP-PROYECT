# SIAP - Sistema Inteligente Asistente Perceptivo

Proyecto de visión artificial que detecta objetos en tiempo real y los describe mediante voz.

## Funcionalidades
- Detección de objetos con YOLOv8
- Identificación de posición (izquierda, centro, derecha)
- Estimación de distancia
- Alertas de peligro
- Interacción por teclado

## Controles
- E - Escanear
- S - Detener
- Q - Salir

## Tecnologías
- Python (Version 3.10)
- OpenCV 
- YOLOv8 (Ultralytics)
- pyttsx3

## librerias internas de python
- Time
- Threading
- queue

## Estado
- Funcionalidades basicas como deteccion y descripcion de objetos basicos, peligro de proximidad y direccion (izquierd, centro, derecha)

## Recomendaciones
- Usar y descargar todo en un entorno virtual (env)
